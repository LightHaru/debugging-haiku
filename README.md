One original haiku about debugging, written to `/output/entry.txt` by a dependency-free `main.ts` running on Node 22.18+ built-ins only. An optional output directory argument is supported for local testing.

## Run it

```sh
node main.ts            # writes /output/entry.txt
node main.ts ./out      # writes ./out/entry.txt
node --test             # runs the smoke test
```
